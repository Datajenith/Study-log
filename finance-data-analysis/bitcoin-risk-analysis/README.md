# Bitcoin Risk Analysis

## Project Overview
This project analyzes Bitcoin price trends and basic risk indicators using Python.

## Technologies Used
- Python
- pandas
- matplotlib
- yfinance

## Analysis Contents
- Bitcoin historical price data collection
- Closing price visualization
- Basic risk analysis through price fluctuations

## Visualization
This project visualizes Bitcoin closing price trends from 2023 to 2026.

## Future Improvements
- Daily return analysis
- Volatility analysis
- Maximum Drawdown (MDD)
- Moving Average indicators
