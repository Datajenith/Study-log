# Bitcoin Risk Analysis

<프로젝트 목적>

지난주에는 비트코인의 가격 데이터를 불러오고 기본적인 시각화를 진행했다.  
이번 주에는 비트코인의 수익률과 변동성을 계산하여 투자 리스크를 간단히 분석해보는 것을 목표로 한다.

<분석 내용>

- 비트코인 가격 데이터 불러오기
- 일간 수익률 계산
- 이동평균선 시각화
- 변동성 계산
- 최대 낙폭(MDD) 계산

<사용 기술>

- Python
- pandas
- matplotlib
- yfinance

<이번 프로젝트에서 배우고 싶은 것>

가격 자체보다 수익률과 리스크 지표가 투자 분석에서 더 중요하다는 점을 이해하고 싶다.
