# Bitcoin Return & Volatility Analysis

## Project Overview
This project analyzes Bitcoin daily returns, volatility, and Maximum Drawdown (MDD) using Python.

## Technologies Used
- Python
- pandas
- matplotlib
- yfinance

## Analysis Contents
- Bitcoin historical price data collection
- Daily return calculation
- Volatility analysis
- Cumulative return visualization
- Maximum Drawdown (MDD) analysis

## Key Insights
- Bitcoin showed high volatility during the analyzed period.
- Large drawdowns indicate high investment risk.
- Return analysis is important for understanding market behavior.

## Future Improvements
- Moving Average indicators
